Gallery 1.2.15 keeps large image libraries responsive while images are being added, processed or deleted.

## Improvements

- Browse existing images while discovery and background processing continue. New images and completed metadata appear automatically without clearing the current view.
- Faster selection previews using the existing thumbnail cache. Rapid selection changes are combined, and late metadata responses cannot overwrite a newer selection.
- Much faster bookkeeping for deleted files, with indexed search cleanup and batched filesystem notifications.
- Reuse unchanged image cards and preserve selection and scroll position during live updates.
- Generate missing thumbnails in the background and reuse current thumbnails during metadata processing. Both Grid and Masonry still share one thumbnail per image.
- Preserve system-trash deletion and show partial failures. Add a short retry delay for images that are still being copied.

## Updating

Requires CyberHub 1.3.0 or newer. Use **Module Manager → Check for updates → Gallery → Update**, then restart CyberHub. Alternatively, import the attached module ZIP through Settings.

Existing images, thumbnails, favorites and collections are retained. No forced rescan or thumbnail rebuild is required.

## Validation

31 automated regression checks passed, plus an isolated browser/import test. In a synthetic 260,000-record catalog, processing 100 deleted-path notifications decreased from about 26 seconds to 0.07 seconds. This measures Gallery bookkeeping; actual storage and system-trash times depend on the machine and NAS.
